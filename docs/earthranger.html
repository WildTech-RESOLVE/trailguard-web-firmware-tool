Connect TrailGuard to EarthRanger

Before You Begin

You need admin access to your EarthRanger site and Nightjar project. Add coordinates for every camera you want shown on the map.

Connections are set per project and are currently in beta. Telegram and email alerts continue as before.

In EarthRanger and Gundi

1

Create the event type

Under Activity › Event Types, create this event type exactly as written:

Event type

Species, category, and severity travel as fields on this event. How those events are presented on your site is configured inside EarthRanger, so your EarthRanger admin is the right person to ask about that.

Required permission

Give the Gundi service account access to the event category containing this type. Without it, events may be accepted and then silently dropped.

2

Create the Gundi connection and route

In Gundi, create a Connection for your EarthRanger site, then a Route that uses it as the destination. Both are required.

Open the Gundi portal

Copy the API key and site name for the Nightjar administrator.

On the Dashboard

3

Check camera coordinates

Every camera needs latitude and longitude under Camera Management. Alerts from cameras without coordinates stay on Telegram and email but are held back from EarthRanger.

4

Paste the key and connect

In Nightjar IQ, go to Admin › Alert Rules. Find the EarthRanger card, paste the API key, add a recognizable site name, and press Connect.

Troubleshooting FAQ

Nothing arrives, but Telegram still works

Check nightjar_detection_rep is an exact match, the Gundi service account can access its event category, and the Route lists your EarthRanger site as its destination.

Some cameras appear and others do not

Check the missing cameras have coordinates under Camera Management. Nightjar does not send an EarthRanger event without a known location.

The detection is on the dashboard, but no event arrived

Only results matching an alert rule and its confidence threshold become alerts. Check whether the image is under Observations instead of Alerts.

It was working, then stopped

Check the key and Nightjar connection, then check the EarthRanger event type is active and its category permissions have not changed.
