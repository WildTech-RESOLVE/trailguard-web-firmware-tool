Activate TrailGuard alerts on Telegram

Before You Begin: Download Telegram and Create a Telegram Account

Everyone who will receive alerts needs the Telegram app and an account. It is free, and runs on Android, iPhone and desktop. If your team already uses Telegram, skip ahead.

Download Telegram

Option A. Alerts to one person

In Telegram

1

Find your chat ID

Open @userinfobot and send it any message. Your Telegram information will be displayed including your Telegram ID number.

Open @userinfobot @userinfobot
2

Start the Alert Bot

Open @TrailGuard_Alerts_bot and press Start.

Open the alert bot @TrailGuard_Alerts_bot

Do not skip this.

Telegram blocks bots from messaging anyone who has not opened a conversation first. Until Start is pressed, alerts are sent from our side and refused on Telegram’s. The dashboard looks healthy and the phone stays quiet.

On the dashboard

3

Add the ID to your project

In Nightjar IQ, go to Admin › Alert Rules. At the top of the page is Project-level recipients (all rules). Press Edit, paste the number into the Telegram row, and save.

To send some alerts to some people, leave them out of the project-level row and add their ID to individual rules instead: threats to the response team, wildlife detections to your ecologists. Anyone in the project-level row is included on top of whatever the individual rules say.

Watch an alert land

Walk past a camera, or wait for a real detection. Until a message has appeared on the phone, treat the setup as unconfirmed. Every failure below looks the same from the dashboard.

Option B. Alerts to a team group

In Telegram

1

Find the group’s chat ID

Add @userinfobot to the group and it reports the group’s ID. You can remove it again afterwards.

Add @userinfobot to a group @userinfobot

A group ID is negative. It starts with a minus sign, like -7642445438. Keep the minus. It is part of the address.

2

Add the alert bot to the group

Add @TrailGuard_Alerts_bot to the group, the same way you add a person.

Add the alert bot to a group @TrailGuard_Alerts_bot

Pressing Start in a private chat does nothing for a group.

The bot has to be a member of the group itself. A group set up correctly on the dashboard but missing the bot receives nothing, and no error is shown anywhere.

On the dashboard

3

Add the group ID to your project

In Nightjar IQ, go to Admin › Alert Rules. At the top of the page is Project-level recipients (all rules). Press Edit, paste the group ID with its minus sign into the Telegram row, and save.

Project-level recipients (all rules)

To send the group only some alerts, leave it out of the project-level row and add the ID to individual rules instead: a response team on threats, a research group on species detections.

Troubleshooting FAQ

No alerts arriving at all, for anyone

For an individual, open Telegram and check there is a conversation with @TrailGuard_Alerts_bot. A chat ID saved on the dashboard is not enough on its own. For a group, check the bot appears in the member list.

Some people get alerts, others don’t

Look at where their chat ID is saved. Anyone in Project-level recipients is on every rule. Anyone added to a single rule gets that rule only.

If someone should be getting everything, move them into the project-level row instead of adding them rule by rule.

It was working, then stopped

Check the chat is not muted and the bot is not blocked on the phone itself. This is the commonest cause and it is invisible from our side. For a group, check the bot is still a member.

I can see the detection on the dashboard, but got no alert

Every transmitted image is classified and kept, but it becomes an alert only if the result matches one of your rules, including the confidence threshold.

Detections that fall below threshold, or come back blank, appear in Observations and send no message. If you expected an alert, check the rule.

A rule I built never fires

Check whether its conditions can occur together. Detection type and species are separate classifications, and an image carries one or the other. A rule asking for Person and a species match at once can never fire.

The dashboard shows an amber notice on rules like this and points you at the default rule that does the job.
